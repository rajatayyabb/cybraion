# Security Policy

## Scope

Cybraion is a research project that demonstrates deterministic policy checks, human approval, audit logging, and provenance-aware escalation for AI-agent actions. It is not a production security boundary by itself.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the maintainer privately through the email listed on the GitHub profile or LinkedIn profile, and include:

- A short description of the affected component
- Reproduction steps using synthetic data
- Expected and actual behavior
- A suggested mitigation, if known

Never include API keys, credentials, personal data, or live customer information.

## Responsible use

Only test Cybraion and connected tools in environments you own or are explicitly authorized to assess.
